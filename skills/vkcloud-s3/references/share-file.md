# Обмен файлом

`s3_presign_get` выдаёт ссылку на разрешённый ключ; укажи срок не выше 604800 секунд. Ограничение профиля может требовать живой проверки: Документированный потолок — 7 дней. Условные PUT/Copy/complete/Delete не подтверждены: запись по умолчанию и move отключены; нужна живая проверка.. Не записывай подпись в журналы. `s3_presign_put` может перезаписать объект и всегда требует подтверждения.
